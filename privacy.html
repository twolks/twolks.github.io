Privacy policy

Twolks Studio · last updated 25 November 2026

Twolks Studio is a private publishing tool operated by the owner of the Twolks YouTube channel. It is used by one person, the channel owner, and only for the Twolks channel.

YouTube API Services

Twolks Studio uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What the tool accesses

  • The Twolks channel's own videos: to upload new videos and set their title, description, tags, thumbnail, chapters, playlist, publish time and content disclosures.
  • The Twolks channel's own analytics (views, watch time, audience retention, subscribers): to decide which topics to cover next.

The tool does not access any other YouTube channel, any viewer's account, or any data beyond what is listed above.

How data is stored and shared

OAuth tokens and analytics figures are stored on a private server controlled by the channel owner, protected by restricted file permissions and network access. They are not sold, shared with third parties or used for advertising. Analytics are kept as long as the channel uses the tool.

Revoking access

The channel owner can revoke Twolks Studio's access at any time at myaccount.google.com/permissions. Stored data is deleted within 30 days of revocation.
